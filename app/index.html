didahSDR - Quick Guide & Shortcuts

UI overall principles

didahSDR focuses on using the mouse to navigate the waterfall and quickly select frequencies.

IQ sources

Open the Source window to switch between VA2GKA Replay (local 96 kHz recording), a local sound card (stereo IQ at 48 / 96 / 192 kHz, centre 0 Hz), and a live KiwiSDR (12 kHz IQ). Paste the receiver web address, for example http://oh5ae.dyndns.org:8073 or http://f4kiy.ddns.net:8073. On live Kiwi the waterfall is a 12 kHz zoom; tuning past the edges or Shift+wheel / ruler-drag slides the Kiwi DDC. Sound-card IQ uses the same DSP as Replay; tick Swap I/Q if the spectrum is reversed. Enable asks for 96 kHz, then 48, then 192 (browsers do not agree on the unconstrained default: Chrome on Linux often reports 44.1 kHz, Firefox may report the PipeWire graph rate). Chrome also hides Pulse Monitor of … loopbacks; create a virtual mic if you need to inject a WAV (see below).

Linux IQ loopback (PipeWire / Pulse): a null sink plus a remap source so Chrome lists it as a microphone. 

pactl load-module module-null-sink sink_name=didah_iq \
  sink_properties=device.description=didahSDR_IQ \
  format=s16le rate=96000 channels=2
pactl load-module module-remap-source source_name=didah_iq_mic \
  master=didah_iq.monitor \
  source_properties=device.description=didahSDR_IQ
ffmpeg -re -stream_loop -1 -i samples/SAMPLE2.wav \
  -f pulse -device didah_iq didahSDR

Chrome on Linux is the awkward case: capture is usually locked to 48 kHz (96 kHz is a Firefox/PipeWire thing), and it may ignore the selected device. After Enable, open pavucontrol → Recording and set the Chromium / Chrome stream to didahSDR_IQ. Or start the browser with that source: 

PULSE_SOURCE=didah_iq_mic chromium

The ffmpeg filename after -f pulse is only a stream label; -device didah_iq is what actually feeds the virtual sink. Then Enable and pick didahSDR_IQ (not a “Monitor of …” entry). IQ is not speaker audio: you should see spectrum around 0 Hz and hear CW after demodulation (Start Audio). Unload with pactl unload-module module-remap-source and pactl unload-module module-null-sink (or restart PipeWire).

Settings

Open the gear button for waterfall levels, WF Speed (1x–8x STFT overlap), CW BFO/BW, iambic A/B, and USB/LSB low/high (default 200–2700 Hz). QRSS (in the WATERFALL section) switches the FFT to a Blackman window and averages successive spectra so slow Morse stands out; WF Speed then sets how long each column integrates.

Mouse behaviours

  • Mouse Wheel: Move the VFO up and down according to the frequency step selected.
  • CTRL + Mouse Wheel / CTRL + Left Drag: Zoom the waterfall, centred on the cursor.
  • SHIFT + Mouse Wheel / SHIFT + Left Drag: Pan the waterfall up and down (on live Kiwi this slides the 12 kHz DDC).
  • CTRL + SHIFT + Wheel / Drag: Step CW bandwidth, or USB/LSB High when in SSB.
  • Left Click on Waterfall: Move the VFO to the selected frequency (hold and drag to track).
  • Left Click on the Ruler: Drag to pan the waterfall up and down.

Local CW transmit

CW mode only, local sidetone — nothing is sent to the server yet. The waterfall freezes while you key (the history from before TX stays on screen) and RX audio is muted. Sidetone is generated on the audio clock so F8/F9/F4 track the paddles without the receive jitter buffer. PTT Off / PTT On arms the typeahead line (bright red). Typing, or clicking PTT On with text already in the box, keys a sidetone at the CW BFO. The buffer grows if you type faster than Morse; when it empties, RX returns after one extra letter-space (no RX between letters). Click PTT On again to disarm (PTT Off); remaining text stays in the box. F8/F9 are an iambic paddle (mode A/B in Settings, B default); F4 is a straight key. Paddles work even when PTT is not armed.

Analog Mechanical Drum Dial (VFO)

  • Hover + Mouse Wheel: Roll any individual digit drum up or down.
  • Left Click on a digit: Selects the digit cursor. Use Arrow Up/Down to spin the drum or type digits 0-9.
  • Right Click on a digit: Zeroes out all digits to the right (convenient rounding tool).
